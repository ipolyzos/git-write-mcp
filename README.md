# git-write-mcp

Controlled, write-capable Git actions exposed as a **stdio** [Model Context Protocol](https://modelcontextprotocol.io/) server for **Cursor** (Linux, macOS). Mutations require explicit approval; read-oriented Git queries belong in a companion read MCP.

**Repository:** https://github.com/ipolyzos/git-write-mcp  

**Contact:** git@ipolyzos.com  

## Status

Early development. Integration branch: `develop`; releases from `main`.
